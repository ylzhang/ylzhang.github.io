## 视觉概念

双 Y 轴帕累托图：
- **左 Y 轴（柱状）**：单个贡献者 commit 数。深海军蓝 `#0B1F3A` 填充柱。
- **右 Y 轴（折线）**：累计占比 %。琥珀金 `#E8A33D` 折线 + 圆点。
- **X 轴**：贡献者按 commit 数降序排名（1-19）。
- **80% 阈值横线**：灰色虚线横贯全图，标 "80% line"，明示"前 3 人已达 64.2%，逼近 80%"。

**关键标注**：
- 在第 3 名位置画一条垂直虚线 + 标签"前 3 = 64.2%"
- 在第 5 名位置画一条垂直虚线 + 标签"前 5 = 73.7%"
- 在第 19 名（即最后）位置画一条垂直虚线 + 标签"其余 14 人 = 26.3%"

**文字语言**：图中所有标签均为**简体中文**（与文章语种一致）。包括：
- 标题：「19 人贡献 12293 次提交」
- 副标题：「DSH 仓库贡献者集中度（按 commit 数降序）」
- 轴标签：「贡献者排名」「提交数」「累计占比」
- 图例：「单提交数（柱）」「累计占比（线）」
- 角注：「数据来源：git shortlog -sn 截至 2026-08-16」

## 关键设计取舍

- **柱状按降序排**——读者一眼看见"前几名远高于后面"。
- **折线 + 阈值线**——把"集中度"量化到 80% 阈值，可视化长尾。
- **双 Y 轴颜色区分**——柱用深蓝、线用琥珀金，避免混淆。
- **不显示真实姓名**——使用 GitHub ID（tianyicui, LegGasai, imccyu, ...），与文章一致。
- **bus factor 可视化**——可以在右下角加一个小的"bus factor = 1-2"角注（按文章第三节），把"为什么前 3 占 64.2% 重要"这个判断固化到图里。
