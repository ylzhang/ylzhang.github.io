## 视觉概念

横向热力图，X 轴 64 天（2026-06-10 → 2026-08-13），Y 轴 0-23 小时段。颜色编码当日当时的 commit 数量。整体趋势应当呈现：
- **6 月初（week 1）**：低密度起步，少量深色块；
- **6 月中下旬（week 2-4）**：capability seam / RFC 012 / Code Mode 节点出现，颜色变深；
- **7 月**：稳态高密度，色块普遍较深（团队进入执行期）；
- **8 月 13 日**：右侧出现一条**纵贯全 Y 轴的亮带**——12 小时 4 版本大爆炸；
- **8/13 之后**：图末稀疏（按文章描述开源后 commit 数明显回落）。

**配色**：单顺序色，从深海军蓝 `#0B1F3A`（无 commit）→ 钢蓝 `#2C4A6B` → 琥珀 `#E8A33D`（极高密度），避开红绿（色弱友好）。背景米白 `#F5F1E8`，刻度深灰 `#3D3D3D`，强调色（标注线）用 `#C0392B`（仅 8/13 当日大爆炸使用）。

**标注**：在 6/13、6/30、8/13 三个关键日期画垂直虚线 + 短文字标签：

## 关键设计取舍

- **不用红绿对比**——色弱友好。
- **不强求精确到 1536 个 cell**——64×24 = 1536 个格子太多，可在 X 方向按天聚合，Y 方向按 4 小时段聚合（24 段 → 6 段：0-3、4-7、8-11、12-15、16-19、20-23），降为 64×6 = 384 个 cell，提升可读性。
- **8/13 单独高亮**——这是文章最重要的单一日期，必须有视觉强度。
- **右下角「数据来源」小字**——保持文章「能确证的标确证」的方法论承诺。
