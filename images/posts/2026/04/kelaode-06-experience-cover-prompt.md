# 封面图生成Prompt

## 文章
标题：编程体验：流式交互的本质优化
Slug：kelaode-06-experience

## 视觉概念
流动的数据河流与键盘——代码和数据像瀑布一样流动，一个极简的键盘在前景，按键发出光芒。整体感觉流畅、即时、响应式。

## Prompt
An immersive programming experience visualization showing a flowing stream of code and data cascading like a luminous waterfall from top to bottom. In the foreground, a minimalist mechanical keyboard with backlit keys glowing in cyan and white. As keys are pressed, ripples of light flow outward merging with the code stream. The stream shows different states: thinking (purple), tool execution (gold), results (green), errors (red). Floating UI elements show progress bars and diff visualizations. The overall feeling is fluid, immediate, and responsive - capturing the essence of stream-based interaction. Color palette: deep space black, electric cyan, soft purple, gold accents, white highlights. 16:9 aspect ratio, modern UI/UX design aesthetic.
