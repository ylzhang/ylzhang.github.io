## 视觉概念
压缩与筛选的意象——大量的信息碎片（文本、代码、图标）从左侧涌入，经过漏斗/过滤器，只有精华部分被保留在右侧。中间有重要性评分的视觉化。

## Prompt
A dynamic information flow visualization showing a stream of data fragments - text snippets, code blocks, document icons, and message bubbles - entering from the left side. These fragments pass through a luminous funnel/filter in the center where importance scoring happens (glowing numbers 0.0-1.0 appear on each fragment). On the right, only the most important fragments emerge as crystallized golden shapes, while faded gray fragments fall away below. The filter mechanism shows attention weights and token count metrics. Background suggests neural network attention patterns with connecting lines. Colors: data fragments in various hues, filter in bright cyan, retained content in gold. 16:9 aspect ratio, information design style.
